🌍 EcoHelper Bot
- Эко-бот в Telegram, который помогает заботиться о планете: рассказывает факты, делится советами, показывает погоду и считает твой углеродный след 🚗💨
 
EcoHelper Bot помогает понять, как твои действия влияют на экологию.
Он предоставляет интересные факты, советы по экономии ресурсов, новости об экологии, прогноз погоды.

---

# Команды

- 📖 /help — список всех команд  
- 🌿 /fact — случайный факт об экологии  
- 💡 /sovet — полезный совет
- 📰 /news — свежие экологические новости с ria.ru  
- 🚗 /co2 — калькулятор углеродного следа
- ☁️ /weather — погода в Москве

---

## 🛠 Установка и запуск
Клонируем репозиторий:
```bash
git clone https://github.com/username/ecobot.git 
cd ecobot
```

Устанавливаем зависимости:
```
pip install -r requirements.txt
```
Создаем бота через @BotFather и получаем токен бота / ссылка на бота -> [BotFather](https://t.me/BotFather )

Регистрируемся и берем API ключ для погоды на OpenWeatherMap / ссылка на сайт -> [OpenWeatherMap](https://openweathermap.org )

Вставляем токены/ключи в ecobot.py:

```
TOKEN = "ВАШ_ТОКЕН_БОТА"
API_KEY = "ВАШ_ТОКЕН_OpenWeatherMap"
```

Запускаем:
```
python ecobot.py
```
